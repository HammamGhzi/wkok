## 4. Appendix — Instagram Algorithm 2026 (biar lu tahu kenapa format post)

Semua dari Hootsuite, Buffer, Metricool, Socialinsider, Inro — bukan blog marketing random.

| Fact | Angka |
|---|---|
| **DM share (send)** | 1 share ≈ **15 likes** |
| **Save** | 1 save ≈ **10 likes** |
| **Likes & follower count** | Bobot mendekati **nol** buat distribusi |
| **Views** | Jadi metrik utama (bukan engagement rate) |
| **Carousel** | Engagement rate **+30,9% YoY**; **9x lebih banyak saves** daripada single image |
| **Reels** | Masih reach tertinggi, tapi **reach turun 35% YoY** |
| **Overall post reach** | **Turun 31% YoY** (Metricool, 1.059.949 akun, ~40 juta posts) |
| **Engagement rate median** | 7,3% (2024) → **5,4%** (2025). IG turun ke **#3**, di bawah LinkedIn & Facebook |
| **Average reach rate** | 3,50%, turun 12% YoY |
| **Original vs repost** | Konten orisinal dapat **40–60%** lebih distribusi |
| **Hashtag** | Sudah **bukan growth lever** sejak follow-hashtag dihapus (late 2024) → ganti ke **social SEO** (keyword di caption, bio, username) |
| **Carousel vs Reels** | "Reels reach strangers, carousels convince them." |

**Implikasi untuk post lu:**

- Post edukatif = konten yang high-**save** by nature
- Karena 1 save ≈ 10 likes, satu carousel yang di-save 50 orang setara 500 likes untuk distribusi
- Format: **carousel**, dengan slide-satu-pesan
- Caption: keyword-rich di 100 karakter pertama (social SEO)
- Hashtag tetap bisa, tapi jangan andalkan
